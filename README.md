# 특순통치 계산기

이 저장소는 특순통치 3단계 통합계산기 v9의 독립 배포본입니다.

## GitHub Pages 공개 설정

1. GitHub에 `sun-geun/teuksun-calculator`라는 **공개(Public)** 저장소를 생성합니다.
2. 저장소 최상위(`main` 브랜치의 `/`)에 `index.html`과 `.nojekyll`을 올립니다.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, Folder: `/ (root)` → Save.
4. 배포 성공 후 `https://sun-geun.github.io/teuksun-calculator/`를 실제로 열어 확인합니다.

> 독립 저장소 생성 및 Pages 설정이 완료되기 전에는 위 웹 주소가 동작하지 않습니다.

배포한 `index.html`은 기존 v9 계산기의 계산 로직을 그대로 유지하고, 기존에 사용하지 않기로 한 교육 브랜드 표기만 정리한 파일입니다.
